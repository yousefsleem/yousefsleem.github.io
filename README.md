# Yousef Hamdy Portfolio

Personal cybersecurity portfolio built with pure HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — responsive design and theme
- `script.js` — menu, theme switcher, reveal animations, active navigation, back-to-top button

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a public repository named `yousefsleem.github.io` (or any repository name if you prefer a project site).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. For the special repository name `yousefsleem.github.io`, the site will be available at `https://yousefsleem.github.io/` after GitHub finishes deployment.
